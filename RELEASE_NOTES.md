# Andy's Selective Grief Protection 0.1.7

Protect selected builds while keeping the explosion rules you choose. This release includes the complete Selective Grief Protection add-on.

- Configure Creeper, charged Creeper, Ghast/fireball, TNT, TNT Minecart, End Crystal, Wither-related, and Unknown explosion sources independently, with per-dimension presets and block categories.
- Craft, own, name, upgrade, and configure Protection Runes. Their square footprints protect 20 blocks above and below the rune, while five tiers raise the maximum radius from 16 to 256 blocks.
- Set member roles and individual player restrictions for building, breaking, containers, interactions, item use, entity attacks, and optional PvP protection.
- Show a cyan emissive footprint grid and independently toggle floating runes, the animated soul flame, and soul-flame sounds. All four rune faces carry a distinct glowing glyph.
- Open personal settings with a stick named `PlayerGriefControl`; operators use `AdminGriefControl` for world controls. BDS operators can use `andys_sgp:admin` without cheats.
- Includes paired Behavior and Resource Packs, PBR assets for Standard graphics and Vibrant Visuals, and add-on product declarations. Retail achievement, graphics, Realm, and BDS qualification remain pending.
- Version 0.1.7 also refines the floating glyph scale. Install both 0.1.7 packs together; saved protection settings are unaffected.

Official project page: [CurseForge](https://www.curseforge.com/minecraft-bedrock/addons/andys-selective-grief-protection)
